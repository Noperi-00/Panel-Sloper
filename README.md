## ✨ امکانات

**کانفیگ و تونل**
- ساخت VLESS روی WebSocket و XHTTP (`packet-up` / `stream-up`)
- ۳ پروتکل × ۲ فینگرپرینت (`chrome` / `ios`) × ۴ ALPN = **۲۴ کانفیگ با یک کلیک** برای هر ساب‌گروه
- تشخیص خودکار دستگاه (iPhone / iPad / Android / Windows / Mac / Linux) روی هر اتصال
- کنترل سرعت تطبیقی، سهمیه حجم، محدودیت IP و انقضا به ازای هر کانفیگ

**گروه‌های ساب‌کریپشن**
- ساب‌گروه با حجم اشتراکی (`total_limit_bytes`) — همهٔ کانفیگ‌های یک گروه یک سهمیه را می‌خورند
- صفحهٔ عمومی اشتراک (`/p/{uuid}`) با رمزنگاری اختیاری، QR کانفیگ و QR ساب
- دسته‌بندی کانفیگ‌ها با رنگ و نام دلخواه + فیلتر در داشبورد

**امنیت و مدیریت**
- ورود با نام کاربری/رمز عبور، rate limit، نشست‌های ۳۶۵ روزه
- نمایش زمان ورود، IP و دستگاه هر نشست + قطع نشست‌های دیگر با یک کلیک
- **انقضای خودکار + قطع خودکار**: هر ۶۰ ثانیه کانفیگ‌های منقضی‌شده یا به‌سررسیده غیرفعال و تمام اتصالات زندهٔ آن‌ها (WS و XHTTP) بلافاصله قطع می‌شوند
- بکاپ/ریستور کامل، export لینک‌ها، لاگ فعالیت و خطاها
- تله‌متری کانتینری (CPU / RAM / شبکه / دیسک) محدود به خود پروسس

**QR و استقرار**
- تولید QR به‌صورت **inline SVG** روی دامنهٔ خودت (`/api/qr`) — بدون هیچ سرویس خارجی
- کشف خودکار Volume پایدار Railway (`RAILWAY_VOLUME_MOUNT_PATH`) + کشف خودکار host
- **بدون کپچا، بدون وابستگی به سرویس بیرونه** — کل پروژه یک FastAPI تک‌پروسه‌ای است

## 🚀 استقرار روی Railway

> **سریع‌ترین راه:** دکمهٔ بالا (یا [این لینک](https://railway.com/new/template/XwqO7j)) را بزن.
> Railway خودش ریپو را می‌گیرد، سرویس را با Volume `/data`، healthcheck `/health` و دستور شروع می‌سازد،
> فقط `ADMIN_USERNAME` و `ADMIN_PASSWORD` را از تو می‌پرسد و سپس دپلوی می‌کند.

**با یک کلیک خودکار انجام می‌شود:** کلون ریپو → ساخت سرویس → Volume روی `/data` → healthcheck → دپلوی.
**تنها کار تو:** وارد کردن `ADMIN_USERNAME` / `ADMIN_PASSWORD` (الزامی).

یا دستی:

1. این ریپو را فورک کن.
2. توی Railway یک پروژهٔ جدید بساز و ریپو را متصل کن.
3. (توصیه‌شده) یک Volume با مسیر `/data` بساز تا داده‌ها روی هر دپلوی حفظ بشن — در غیر این صورت پروژه روی دیسک موقت کار می‌کند.
4. متغیرها را تنظیم کن، دپلوی کن و تمام.

| Variable | مقدار | ضرورت |
|---|---|---|
| `ADMIN_USERNAME` | `Noperi` یا هر نامی | الزامی |
| `ADMIN_PASSWORD` | یک رمز قوی حداقل ۱۰ کاراکتر | الزامی در production |
| `SECRET_KEY` | یک رشتهٔ تصادفی طولانی | الزامی برای پایداری نشست |
| `RAILWAY_PUBLIC_DOMAIN` | دامنهٔ عمومی سرویس | برای درست ساختن لینک‌های کانفیگ |
| Volume | Mount Path: `/data` | توصیه‌شده — برای پایدار ماندن داده‌ها |

> مقادیر پیش‌فرض `Noperi` / `Noperi` فقط برای راه‌اندازی اولیه هستند؛ حتماً بعد از اولین ورود از بخش تنظیمات تغییرشان بده.
> اگر روزی رمزت کار نکرد (مثلاً بعد از ری‌دپلوی با حجم قدیمی)، متغیر `ADMIN_PASSWORD_RESET=1` را یک‌بار تنظیم کن تا از نو seed شود.

### 💻 اجرای محلی

```bash
git clone https://github.com/noperi0000-netizen/Panel-Sloper.git
cd Panel-Sloper
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ADMIN_USERNAME='Noperi'
export ADMIN_PASSWORD='یک-رمز-قوی'
export SECRET_KEY='یک-کلید-تصادفی'
uvicorn main:app --host 0.0.0.0 --port 8000
```

سپس `http://localhost:8000/login` را باز کن.

## 📦 ساخت سریع کانفیگ

بعد از ورود به پنل:

1. از منوی **ساب‌گروه‌ها** یک گروه جدید بساز (نام + حجم اشتراکی + تعداد روز + محدودیت IP).
2. دکمهٔ **ساخت سریع** را بزن — پنل به‌صورت خودکار **۲۴ کانفیگ** می‌سازد:
   - پروتکل: `vless-ws` ، `xhttp-packet-up` ، `xhttp-stream-up`
   - فینگرپرینت: `chrome` ، `ios`
   - ALPN: `def` ، `h2` ، `http1.1` ، `h2,http1.1`
3. همهٔ کانفیگ‌های یک گروه **یک سهمیهٔ حجمی اشتراکی** می‌خورند.
4. QR هر کانفیگ و لینک ساب عمومی از همان صفحه قابل دریافت است.

نام‌گذاری کانفیگ‌ها: `{PROTO}-{FP}-{ALPN}-{NUM}` (مثلاً `vless-ws-chrome-h2-3`).

## 🧱 معماری

| فایل | نقش |
|---|---|
| `main.py` | FastAPI — API، احراز هویت، persistence، تله‌متری، reaper، QR |
| `pages.py` | رابط کاربری (لاگین، داشبورد، صفحهٔ عمومی ساب) |
| `relay_vless.py` | تونل VLESS روی WebSocket |
| `xhttp_siz10.py` | ترابرد XHTTP با quota gate تطبیقی |
| `speed_limit.py` | کنترل سرعت |
| `railway.json` | healthcheck `/health` + restart policy + volume mount |

**پایداری داده‌ها** — `DATA_DIR` از `RAILWAY_VOLUME_MOUNT_PATH` خوانده می‌شود؛ اگر Volume نباشد، `/app/data` موقت استفاده می‌شود و هیچ خطایی نمی‌گیرد. host کشف‌شده داخل `host.txt` ذخیره می‌شود تا لینک‌های کانفیگ بعد از ری‌دپلوی یکسان بمانند.
